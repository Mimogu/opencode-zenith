# /grill-me: Design Alignment Interview

Interactively stress-test assumptions and align on design decisions for: $ARGUMENTS

## Protocol

1. **Analyze Proposal**: Break down the proposed architecture or feature into core assumptions, trade-offs, and failure modes.
2. **Sharp Interview Questions**:
   - Ask 3 to 5 targeted, multiple-choice or direct questions about:
     - Edge cases and error handling requirements.
     - Performance constraints and data volume expectations.
     - Breaking changes or backwards-compatibility needs.
     - UX vs complexity trade-offs.
3. **Synthesis**:
   - Once the user answers, produce a hardened design specification before any code is touched.
